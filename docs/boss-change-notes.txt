ENTRY 1 — Product uniqueness / no duplicate catalogue rows
Date: 14 Oct 2026
Sample to verify: ASK123
--------------------------------------------------------------------------------

WHAT BOSS ASKED
  - Able to create duplicate product details (same model like ASK123).
  - Clarify: what is the unique key?

FINDING (as explained)
  - Database unique key is ONLY: (tenantId, sku)
  - Model name (e.g. ASK123) is NOT unique.
  - Brand, HSN, description are NOT unique.
  - Old create flow appended a random SKU suffix (…-ASK123-XXXX), so each
    create looked unique to the DB even when the model name was the same.

CHANGES MADE
  1. Inventory hub (Edit/Add product drawer)
     - Before create: block if same model name + same brand already exists.
     - Clear error toast pointing to existing SKU; ask to edit instead.
     - SKU generation is now deterministic (no random time suffix).
       Format: HMS-{family}-{industry}-{brand?}-{model}

  2. Products page (create flow)
     - Same duplicate check (name + brand).
     - Same deterministic SKU generation.

  3. API error message (P2002 / SKU conflict)
     - Clearer 409 text: product with this SKU already exists; open existing
       product to edit — model name alone is not unique.

FILES TOUCHED
  - src/pages/erp/InventoryHubPage.tsx
  - src/pages/erp/ProductsPage.tsx
  - backend/src/middleware/error.middleware.ts

NOT DONE / NOTE FOR BOSS
  - Existing duplicate ASK123 rows already in DB are NOT auto-deleted.
    Clean up / merge manually if needed.
  - Unique constraint in DB remains (tenant_id, sku) — unchanged schema.
